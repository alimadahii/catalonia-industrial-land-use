# Catalonia Industrial Land Use Web Map

This repository contains an interactive web map visualising the evolution of industrial and commercial land use (LU_121) across municipalities in Catalonia between 1990 and 2018.

The map uses a draggable radar chart. When the chart is moved across the map, the municipality under the centre of the chart is highlighted and the corresponding LU_121 values are displayed directly on the chart.

## Data

The visualisation is based on municipal-level GeoJSON data derived from CORINE Land Cover class 121, representing industrial and commercial land use. Values are expressed in square kilometres.

The years represented are:

- 1990
- 2000
- 2006
- 2012
- 2018

## Technologies

This project was built using:

- Leaflet
- Chart.js
- Chart.js DataLabels plugin
- Turf.js
- GeoJSON
- GitHub Pages
